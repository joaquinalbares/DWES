7. ESTRUCTURAS DE CONTROL EMBEBIDAS

Para controlar la generación dinámica del lenguaje de marcas, se utilizan sintaxis alternativas en las estructuras de control dentro del HTML.

A. Condicional Embebido (if / else)

<?php $usuarioAutenticado = true; ?>

<!DOCTYPE html>
<html lang="es">
<head>
    <title>Panel de Control</title>
</head>
<body>
    <?php if ($usuarioAutenticado): ?>
        <h2>Bienvenido, Administrador</h2>
        <p>Tienes acceso al panel privado.</p>
    <?php else: ?>
        <h2>Acceso Denegado</h2>
        <p>Por favor, inicia sesión.</p>
    <?php endif; ?>
</body>
</html>

B. Bucles Embebidos (foreach)

<?php 
$productos = ["Teclado Mecánico", "Ratón Óptico", "Monitor 27''"];
?>

<h3>Catálogo de Productos</h3>
<ul>
    <?php foreach ($productos as $producto): ?>
        <li><?= $producto ?></li>
    <?php endforeach; ?>
</ul>
