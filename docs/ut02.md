## 2. CONTENIDOS

### 1. INSERCIÓN DE CÓDIGO Y TECNOLOGÍAS ASOCIADAS

El mecanismo de generación de páginas web dinámicas en el servidor consiste en **embeber o incrustar bloques de código fuente ejecutable dentro de un documento de lenguaje de marcas (HTML)**.

```
┌────────────────────────────────────────────────────────┐
│ Servidor Web                                           │
│ ┌──────────────────────┐      ┌──────────────────────┐ │
│ │ Documento HTML       │ ──>  │ Intérprete (ej. PHP) │ │
│ │  + Código Embebido   │      │ Procesa el código    │ │
│ └──────────────────────┘      └──────────┬───────────┘ │
└──────────────────────────────────────────┼─────────────┘
                                           │ Genera HTML puro
                                           ▼
┌────────────────────────────────────────────────────────┐
│ Navegador Cliente (Recibe sólo el resultado final)     │
│ <h1>Hola Carlos</h1>                                   │
└────────────────────────────────────────────────────────┘

```

#### A. Flujo de Obtención del Lenguaje de Marcas
1. El cliente solicita un archivo con extensión ejecutable (ej. `.php`).
2. El servidor web analiza el documento e identifica los bloques delimitados por etiquetas especiales.
3. El intérprete ejecuta las sentencias, procesa variables, operaciones o accesos a bases de datos.
4. Las sentencias de salida (como `echo` o `print`) sustituyen al bloque de código original, transformándolo en HTML puro.
5. El cliente recibe únicamente el resultado final en lenguaje de marcas sin ver el código fuente servidor.

#### B. Principales Tecnologías Asociadas
A continuación se listan las principales tecnologías asociadas con el lenguaje de marcas con código embebido PHP:

| Tecnología | Desarrollador | Descripción / Entorno |
| --- | --- | --- |
| **PHP** | The PHP Group / Open Source | Lenguaje interpreted multipropósito, ampliamente extendido y nativamente embebible en HTML. |
| **ASP.NET** | Microsoft | Framework para ejecución de código servidor (.NET) en páginas C# o VB. |
| **JSP / Servlets** | Oracle / Jakarta EE | JavaServer Pages; compilan a Servlets de Java para ejecutar lógica en servidores como Tomcat. |
| **Python** | Python Software Foundation | Utilizado mediante frameworks web (WSGI/ASGI) o motores de plantillas como Jinja2. |

### 2. SINTAXIS BÁSICA Y ETIQUETAS DE INSERCIÓN EN PHP

#### A. Etiquetas de Apertura y Cierre

Para delimitar dónde empieza y termina el código en servidor, se utilizan las siguientes etiquetas:

```html
<!-- Etiqueta estándar completa -->
<?php 
    echo "Código ejecutado en el servidor"; 
?>

<!-- Etiqueta corta de impresión (Short Echo Tag) -->
<?= "Impresión directa equivalente a <?php echo ..." ?>

```

> **Nota:** La instrucción o sentencia simple siempre finaliza obligatoriamente con punto y coma (`;`).

#### B. Directivas de Configuración

Mediante la directiva `ini_set()` o modificando el archivo `php.ini`, podemos alterar el comportamiento predeterminado de la ejecución (por ejemplo, la visualización de errores o el uso de *short tags*):

```php
<?php
// Modificar la directiva para mostrar errores en entorno de desarrollo
ini_set('display_errors', '1');
error_reporting(E_ALL);
?>

```

#### C. Comentarios

```php
<?php
// Comentario de una sola línea

# Comentario de una sola línea tipo consola

/*
  Comentario multilínea
  útil para bloques extensos
*/
?>
```

### 3. TIPOS DE DATOS Y CONVERSIONES

PHP es un lenguaje de **tipado débil y dinámico**. La variable adopta el tipo de dato según el valor asignado.

#### A. Tipos Escalares Principales

* **Booleano (`bool`):** `true` o `false`.
* **Entero (`int`):** Números enteros (ej. `42`, `-10`).
* **Coma flotante (`float`):** Números con decimales (ej. `19.99`).
* **Cadena de texto (`string`):** Secuencia de caracteres delimitada por comillas simples (`' '`) o dobles (`" "`).

#### B. Conversión entre Tipos de Datos (*Type Casting*)

Podemos forzar la conversión de un tipo de dato a otro usando operadores de fundición (*casting*):

```php
<?php
$cadena = "105.5 productos";

// Conversión explícita
$entero = (int)$cadena;      // Resultado: 105
$flotante = (float)$cadena;  // Resultado: 105.5
$booleano = (bool)$entero;   // Resultado: true
?>
```

### 4. VARIABLES, CONSTANTES Y ÁMBITOS

#### A. Variables y Asignaciones
Las variables se identifican siempre con el símbolo `$` y siguen la regla de nombrado *kebab-case* o *camelCase* (deben comenzar con una letra o guion bajo).

```php
<?php
$nombreUsuario = "Carlos"; // Asignación de cadena
$edad = 25;               // Asignación de entero
$precio = 49.95;         // Asignación de flotante
?>
```

#### B. Constantes
Representan valores fijos que no cambian durante la ejecución del script.

```php
<?php
// Definición tradicional
define("IMPUESTO_IVA", 0.21);

// Definición moderna (palabra clave const)
const NOMBRE_SITIO = "IES Los Albares";

echo IMPUESTO_IVA; // Muestra: 0.21
?>

```

#### C. Ámbitos de las Variables (*Scope*)
El ámbito determina la visibilidad o alcance de una variable en el programa:

1. **Ámbito Local:** Variables declaradas dentro de una función; solo son accesibles desde el interior de la misma.
2. **Ámbito Global:** Variables declaradas fuera de las funciones. Para acceder a ellas dentro de una función se requiere la palabra clave `global` o la matriz `$GLOBALS`.
3. **Ámbito Estático (`static`):** Mantiene su valor entre sucesivas llamadas a una función.

```php
<?php
$variableGlobal = 100;

function probarAmbito() {
    global $variableGlobal; // Importar variable global
    static $contador = 0;   // Se conserva entre llamadas
    
    $contador++;
    echo "Contador: " . $contador . " | Global: " . $variableGlobal;
}
?>

```

### 5. VARIABLES DEL SISTEMA (SUPERGLOBALS)
PHP proporciona un conjunto de variables asociativas predefinidas accesibles desde cualquier punto del código:

| Variable | Propósito |
| --- | --- |
| `$_GET` | Captura los parámetros pasados en la URL (Query String). |
| `$_POST` | Recoge los datos enviados mediante un formulario HTML por el método POST. |
| `$_SERVER` | Contiene metadatos de las cabeceras, rutas y entorno de ejecución del servidor. |
| `$_COOKIE` | Guarda los valores transmitidos por las cookies del cliente. |
| `$_SESSION` | Gestiona variables persistentes entre distintas peticiones de un usuario. |

### 6. OPERADORES EN PHP

#### A. Operadores Aritméticos y de Asignación
Estos operadores se encargar de realizar operaciones matemáticas básicas y asignaciones de variables.

```php
<?php
$a = 10;
$b = 3;

$suma = $a + $b;       // 13
$modulo = $a % $b;     // 1 (resto de la división)
$a += 5;               // Equivalente a $a = $a + 5;
?>
```

#### B. Operadores de Comparación e Identidad

```php
<?php
$num = "10";

// Comparación débil (Igualdad en valor)
var_dump($num == 10);  // true

// Comparación estricta (Igualdad en valor y tipo)
var_dump($num === 10); // false

// Operador de fusión de nulos (Null Coalescing)
$usuario = $_GET['user'] ?? 'Invitado';
?>

```
