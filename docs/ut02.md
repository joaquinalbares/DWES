## 1. INSERCIÓN DE CÓDIGO Y TECNOLOGÍAS ASOCIADAS

El mecanismo de generación de páginas web dinámicas en el servidor consiste en **embeber o incrustar bloques de código fuente ejecutable dentro de un documento de lenguaje de marcas (HTML)**.

```
┌────────────────────────────────────────────────────────┐
│ Servidor Web                                           │
│ ┌──────────────────────┐      ┌──────────────────────┐ │
│ │ Documento HTML       │ ──>  │ Intérprete (ej. PHP) │ │
│ │  + Código Embebido   │      │ Procesa el código    │ │
│ └──────────────────────┘      └──────────┬───────────┘ │
└──────────────────────────────────────────┼─────────────┘
                                           │ Genera HTML puro
                                           ▼
┌────────────────────────────────────────────────────────┐
│ Navegador Cliente (Recibe sólo el resultado final)     │
│ <h1>Hola Carlos</h1>                                   │
└────────────────────────────────────────────────────────┘

```

### A. Flujo de Obtención del Lenguaje de Marcas
1. El cliente solicita un archivo con extensión ejecutable (ej. `.php`).
2. El servidor web analiza el documento e identifica los bloques delimitados por etiquetas especiales.
3. El intérprete ejecuta las sentencias, procesa variables, operaciones o accesos a bases de datos.
4. Las sentencias de salida (como `echo` o `print`) sustituyen al bloque de código original, transformándolo en HTML puro.
5. El cliente recibe únicamente el resultado final en lenguaje de marcas sin ver el código fuente servidor.

### B. Principales Tecnologías Asociadas
A continuación se listan las principales tecnologías asociadas con el lenguaje de marcas con código embebido PHP:

| Tecnología | Desarrollador | Descripción / Entorno |
| --- | --- | --- |
| **PHP** | The PHP Group / Open Source | Lenguaje interpreted multipropósito, ampliamente extendido y nativamente embebible en HTML. |
| **ASP.NET** | Microsoft | Framework para ejecución de código servidor (.NET) en páginas C# o VB. |
| **JSP / Servlets** | Oracle / Jakarta EE | JavaServer Pages; compilan a Servlets de Java para ejecutar lógica en servidores como Tomcat. |
| **Python** | Python Software Foundation | Utilizado mediante frameworks web (WSGI/ASGI) o motores de plantillas como Jinja2. |

## 2. SINTAXIS BÁSICA Y ETIQUETAS DE INSERCIÓN EN PHP

### 2.1. Etiquetas de Apertura y Cierre

Para delimitar dónde empieza y termina el código en servidor, se utilizan las siguientes etiquetas:

```html
<!-- Etiqueta estándar completa -->
<?php 
    echo "Código ejecutado en el servidor"; 
?>

<!-- Etiqueta corta de impresión (Short Echo Tag) -->
<?= "Impresión directa equivalente a <?php echo ..." ?>

```

/// admonition | Fin de linea
La instrucción o sentencia simple siempre finaliza obligatoriamente con punto y coma (`;`).
///


### 2.2. Sintaxis de PHP

El elemento básico en PHP es el bloque. Un bloque PHP está delimitado por las etiquetas de apertura y cierre y contiene una serie de sentencias separadas por punto y coma.

```php
<?php
    sentencia1;
    sentenciaN;
?>

```

/// tip | RECOMENDACIÓN
Cuando un fichero contiene solo PHP se recomienda no cerrar la etiqueta del último bloque. 
Puede dar problemas si la respuesta del servidor involucra varios ficheros.
///

## 3. VARIABLES, TIPOS DE DATOS Y CONVERSIONES

PHP es un lenguaje de **tipado débil y dinámico**. La variable adopta el tipo de dato según el valor asignado.

### 3.1. Declaración de variables

En PHP los identificadores de las variables comienzan siempre con el carácter `$`. El identificador de la variable **debe comenzar** por una letra o un guion bajo (`_`), y puede estar formado por números, letras y guiones bajos. Se sigue la regla de nombrado *kebab-case* o *camelCase*.

Para declarar una variable, solo hay que asignarle un valor:
`$nombre = valor;`

La siguiente sentencia declara la variable `$numero` y se le asigna el valor `4`, por lo que será de tipo `integer`.

```php
$numero = 4;
```

/// danger | Variables no inicializadas

Si se invoca a una variable antes de asignarle un valor, se muestra por pantalla un aviso, pero no se interrumpe la ejecución del script. Si una variable no inicializada toma el valor por defecto para ese tipo de dato.
///

### 3.2. Tipos de Datos

Esta tabla muestra los tipos de datos que se usan en PHP. Los cuatro primeros son escalares

| Tipo | Descripción |
|: --- :|: --- :|
| `integer` | Números enteros (ej. `42`, `-10`) 
| `float` | Números reales en coma flotante (ej. `19.99`) 
| `string` | Secuencia de caracteres delimitada por comillas simples (`' '`) o dobles (`" "`) 
| `boolean` | Booleanos, `TRUE` o `FALSE` 
| `array` | Colección de elementos identificados 
| `object` | Un objeto es una instancia de una clase 
| `callable` | Para las funciones de *callback* 
| `null` | Para representar variables no asignadas 
| `resource` | Representa recursos externos 

Algunos aspectos a destacar:
- La conversión entre `integer` y `float` es automática. Si se recibe un `float` y esperamos un `integer`, se trunca. 
- Si al realizar una operación sobre un entero el resultado tiene decimales, se convierte a `float`.
- Para delimitar una cadena es posible utilizar comillas simples o dobles, pero hay una diferencia. Si se utilizan comillas dobles (también llamadas comillas mágicas), las variables que aparezcan dentro de la cadena se sustituirán por su valor.

### 3.3. Operadores

PHP soporta un conjunto completo de operadores aritméticos, lógicos, de comparación y de asignación:

```php
<?php
// Operadores Aritméticos: +, -, *, /, %, **
$suma = 5 + 3;
$potencia = 2 ** 3; // 8

// Operadores de Comparación Estricta vs Débil
var_dump(5 == "5");  // bool(true) - Compara solo valor
var_dump(5 === "5"); // bool(false) - Compara valor y tipo de dato

// Operador Nave Espacial <=> (Spaceship, PHP 7+)
// Devuelve -1 (menor), 0 (igual), 1 (mayor)
echo 1 <=> 2; // -1
echo 2 <=> 2; // 0
echo 3 <=> 2; // 1

// Operador de Fusión de Nulo ?? (Null Coalescing)
$usuario = $_GET['user'] ?? 'Invitado'; // Si no existe $_GET['user'], asigna 'Invitado'

// Operador de Cadena (Concatenación .)
$texto = "Hola " . "Mundo";
```

### 3.4. Conversión entre Tipos de Datos (*Type Casting*)
Las variables pueden cambiar de tipo dinámicamente:

```php
<?php
$a = 5;          // entero
var_dump($a);    // imprime el tipo de dato, el tamaño y el valor de a
echo "<br>";
$a = "Hola";     // cambia a cadena
var_dump($a);    // se comprueba que ha cambiado
```

También podemos forzar la conversión de un tipo de dato a otro usando operadores de fundición (*casting*):

```php
<?php
$cadena = "105.5 productos";

// Conversión explícita
$entero = (int)$cadena;      // Resultado: 105
$flotante = (float)$cadena;  // Resultado: 105.5
$booleano = (bool)$entero;   // Resultado: true
?>
```

### 3.5. Constantes
Representan valores fijos que no cambian durante la ejecución del script.

```php
<?php
// Definición tradicional
define("IMPUESTO_IVA", 0.21);

// Definición moderna (palabra clave const)
const NOMBRE_SITIO = "IES Los Albares";

echo IMPUESTO_IVA; // Muestra: 0.21
?>

```

### 3.6. Ámbitos de las Variables (*Scope*)
El ámbito determina la visibilidad o alcance de una variable en el programa:

1. **Ámbito Local:** Variables declaradas dentro de una función; solo son accesibles desde el interior de la misma.
2. **Ámbito Global:** Variables declaradas fuera de las funciones. Para acceder a ellas dentro de una función se requiere la palabra clave `global` o la matriz `$GLOBALS`.
3. **Ámbito Estático (`static`):** Mantiene su valor entre sucesivas llamadas a una función.

```php
<?php
$variableGlobal = 100;

function probarAmbito() {
    global $variableGlobal; // Importar variable global
    static $contador = 0;   // Se conserva entre llamadas
    
    $contador++;
    echo "Contador: " . $contador . " | Global: " . $variableGlobal;
}
?>

```

### 3.7. Variables del Sistema (SUPERGLOBALS)

PHP proporciona un conjunto de variables predefinidas accesibles desde cualquier parte:

| Variable | Descripción |
| --- | --- |
| `$GLOBALS` | Variables globales definidas en la aplicación |
| `$_SERVER` | Contiene metadatos de las cabeceras, rutas y entorno de ejecución del servidor. |
| `$_GET` | Captura los parámetros pasados en la URL (Query String). |
| `$_POST` | Recoge los datos enviados mediante un formulario HTML por el método POST. |
| `$_COOKIE` | Guarda los valores transmitidos por las cookies del cliente. |
| `$_SESSION` | Gestiona variables persistentes entre distintas peticiones de un usuario. |
| `$_REQUEST` | Contiene la información de `$_GET`, `$_POST` y `$_COOKIE` |
| `$_ENV` | Variables de entorno |

## 4. OPERADORES EN PHP

### 4.1. Operadores Aritméticos y de Asignación
Estos operadores se encargar de realizar operaciones matemáticas básicas y asignaciones de variables, asi como operaciones de lógica y comparación.

```php
<?php
// Operadores Aritméticos: +, -, *, /, % -> resto de la división, ** -> potencia
$a = 10;
$b = 3;

$suma = $a + $b;       // 13
$modulo = $a % $b;     // 1 (resto de la división)
$potencia = $a ** $b;    // 1000
$a += 5;               // Equivalente a $a = $a + 5;
?>
```

### 4.2. Operadores de Comparación e Identidad

```php
<?php
$num = "10";

// Comparación débil (Igualdad en valor)
var_dump($num == 10);  // true

// Comparación estricta (Igualdad en valor y tipo)
var_dump($num === 10); // false

// Operador Nave Espacial <=> (Spaceship, PHP 7+)
// Devuelve -1 (menor), 0 (igual), 1 (mayor)
echo 1 <=> 2; // -1
echo 2 <=> 2; // 0
echo 3 <=> 2; // 1

// Operador de Fusión de Nulo ?? (Null Coalescing)
$usuario = $_GET['user'] ?? 'Invitado'; // Si no existe $_GET['user'], asigna 'Invitado'
?>
```

### 4.3. Operadores de Cadenas (String)

En PHP existen dos operadores principales para trabajar con cadenas de texto (strings): [1] 

- **A. Operador de concatenación (.)**
    Une dos cadenas de texto y devuelve el resultado de la combinación.
    
    ```php
    $a = "Hola ";
    $b = $a . "Mundo!"; // $b contiene "Hola Mundo!"
    ```

- **B. Operador de asignación concatenante (.=)**
    Añade (concatena) la cadena del lado derecho a la variable que está en el lado izquierdo, modificando su valor original.
    
    ```php
    $a = "Hola ";
    $a .= "Mundo!"; // $a ahora contiene "Hola Mundo!"
    ```
